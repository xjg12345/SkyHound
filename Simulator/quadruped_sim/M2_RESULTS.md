# M2 四狗导航和 P450 共场实测

环境：ROS Noetic、Gazebo Classic 11.15.1、P450 PX4 SITL。测试使用独立的 ROS 和 Gazebo 端口，没有修改原无人机启动脚本、世界或规划器。

| 验收项目 | 实测结果 |
| --- | --- |
| 四狗独立导航 | 5/5 轮通过；每轮四个目标全部到达，未记录非地面接触，取消 `dog1` 后其他三台的任务仍在执行 |
| 注入纯 P450 | 四台到达，终点误差 0.195–0.202 m，无非地面接触；退出后只剩原 P450 和场景模型，MAVROS 仍连接 |
| 注入默认 P450 D435i | 四台到达，终点误差 0.196–0.213 m，最长航向误差 0.253 rad，28.63 s 完成测试，无非地面接触 |
| D435i 注入退出回归 | 原 Gazebo 继续运行，`p450_D435i_0` 保留，四台狗清理完毕，`/use_sim_time` 保持 `false`，MAVROS 状态 `connected=true` |
| 无人机链 | 退出后收到深度图、OctoMap 点云和 Prometheus 状态的新消息；EGO、OctoMap 和 UAV 控制节点仍在线 |
| M1 回归 | 单狗目标取消 `PREEMPTED`，最终速度指令 0.037 s 内归零 |

D435i 共场原始测试输出：

```json
{"actions":{"dog1":3,"dog2":3,"dog3":3,"dog4":3},"cancel_isolated":true,"contacts":0,"error_m":{"dog1":0.197,"dog2":0.196,"dog3":0.206,"dog4":0.213},"mode":"attach","settle_drift_max_m_or_rad":{"dog1":0.0176,"dog2":0.0165,"dog3":0.0172,"dog4":0.0172},"settled_speed":{"dog1":0.046,"dog2":0.046,"dog3":0.046,"dog4":0.046},"wall_s":28.63,"yaw_error_rad":{"dog1":0.214,"dog2":0.253,"dog3":0.227,"dog4":0.227}}
```

停车判定检查连续两秒的实际位置和航向相对起始样本的最大偏移，以及最终速度命令归零。`settle_drift_max_m_or_rad` 为两项各取各自单位后较大的数值；Gazebo 单帧模型速度作为诊断数据，不单独用于停车判定。

共场时验证了 40 个柱体的名称和摆放。原世界有两个重叠柱体，启动后各分离约 0.25 m；地图按分离后稳定位置生成。P450 保持未解锁，本次未验证实际起飞、空中联动、窄通道多机调度或物理四足步态。图形 launch 已解析验证，未验收实际窗口渲染。启动及复跑命令见 [使用说明](README.md)。
